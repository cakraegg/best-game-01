GLOWTIDE v2: Neon Tide Run is a small original 2D arcade game. You steer a lantern-skiff across a dark bioluminescent sea, gathering tide pearls to build a combo while dodging urchin mines, darting eels, and tide wraiths. Ten waves stand between you and the dawn — and the Tide Leviathan waits on waves 5 and 10. The only way to wound it is to dash straight through its body. After every wave, pick 1 of 3 blessings: a faster skiff, double pearls, an aegis shield, a wider magnet, a quicker dash, an extra life, or lantern oil. A full lantern bursts and clears every hazard in reach. Synthesized WebAudio sounds, no assets, no libraries, no network requests. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or the arrow keys (or hold the mouse button to steer), Space to dash, P to pause, M to mute, R to restart after game over. On a blessing screen, press 1, 2 or 3 — or click a card.
