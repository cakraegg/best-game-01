GLOWTIDE: Neon Tide Run is a small original 2D arcade game. You steer a lantern-skiff across a dark bioluminescent sea, collecting glowing tide pearls to build a combo while dodging drifting urchin mines. Three lives, waves that get faster and denser, a dash with a cooldown, and synthesized WebAudio sounds — no assets, no libraries, no network requests. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or the arrow keys (or hold the mouse button to steer), Space to dash, P to pause, M to mute, R to restart after game over.
